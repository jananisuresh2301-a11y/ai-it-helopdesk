# Account & Password Issues

## Locked Out After Failed Login Attempts
Symptoms: "Account locked" message after multiple wrong password attempts.

Steps:
1. Wait for the lockout timer to expire (typically 15-30 minutes) or
   contact IT to unlock immediately.
2. Verify Caps Lock / keyboard layout isn't causing repeated failures.
3. Use the self-service password reset portal if enabled for the org.
4. Confirm the account isn't disabled due to inactivity or offboarding.

## Forgotten Password
Symptoms: User can't remember their password and has no active session.

Steps:
1. Direct the user to the self-service password reset (SSPR) portal.
2. Verify identity via MFA (registered phone/email) before resetting.
3. If SSPR isn't set up, IT resets the password manually and issues a
   temporary password that must be changed at next login.

## MFA Device Lost or Unavailable
Symptoms: User can log in with password but can't complete MFA challenge.

Steps:
1. Use backup MFA method if registered (backup codes, secondary device).
2. IT verifies identity through an alternate channel (e.g. manager
   confirmation, ID check) before resetting MFA enrollment.
3. Re-enroll the user's new device in the MFA app.
