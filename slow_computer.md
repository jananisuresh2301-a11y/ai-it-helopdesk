# Slow Computer / Performance Issues

## General Slowness at Startup
Symptoms: Computer takes a long time to boot or become responsive after
login.

Steps:
1. Check startup programs and disable unnecessary ones (Task Manager >
   Startup on Windows; System Settings > General > Login Items on macOS).
2. Check available disk space — less than 10-15% free space on the system
   drive causes major slowdowns.
3. Run a malware/antivirus scan.
4. Check for pending OS updates that may be running in the background.

## Slowness During Normal Use
Symptoms: Apps freeze, high fan noise, spinning cursor.

Steps:
1. Open Task Manager / Activity Monitor and identify the process consuming
   the most CPU or memory.
2. Close unused browser tabs and background applications.
3. Check for a runaway process or update that's stuck (e.g. indexing,
   backup software, sync clients like OneDrive/Dropbox).
4. Restart the machine — clears memory leaks in long-running sessions.
5. If memory usage is consistently near 100%, consider a RAM upgrade or
   review installed applications for known memory leaks.

## Disk Nearly Full
Symptoms: "Low disk space" warnings, slow file saves.

Steps:
1. Run disk cleanup / storage management tools to clear temp files and
   old updates.
2. Empty the recycle bin / trash.
3. Move large files (videos, archives) to external or cloud storage.
4. Check Downloads folder — commonly accumulates large unused files.
